PROBLEM FOUND
  Summary 002 said "swapchain 1920x1080 in both modes", but nothing set the libnx window size on the Vulkan path:
  window_switch.cpp's 1920x1080 only sized the rex Window object. plume's swapchain takes nwindowGetDimensions,
  which reports 1280x720 until nwindowSetDimensions is called (libnx native_window.h). Only the deko3d path (Switch 1)
  set it. So the Switch 2 build would most likely have presented 1280x720 in both modes. The "LO keeps 1080p" note
  was wrong too: LO outputs 2560x1440 docked (settings/config.cpp Validate, gpu/video.cpp nwindowSetDimensions with a
  1920x1080 fallback, hbmenu_1440p_fix.txt; LO summary_047/048 logs ran docked at 2560x1440).
